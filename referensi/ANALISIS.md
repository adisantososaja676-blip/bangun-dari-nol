# Bedah Video Referensi

Sumber: video @ngekepoyuk.id tentang jembatan (98 detik, 720×1280, 9:16). Untuk studi format saja. Karakter dan gaya visualnya **tidak** ditiru.

## Struktur

- **Hook (0–3 dtk):** "Nyeberang jurang modal kayu sama…, bisa nggak?"
- **Maskot:** "Bang Hakim", pekerja low-poly berhelm kuning, jadi pemecah masalah tetap
- **Rantai evolusi solusi:**
  1. Balok kayu → *melengkung, patah di tengah*
  2. Jembatan tali + papan (gaya tarik) → *talinya melendut*, hanya untuk pejalan kaki
  3. Menara + kabel baja (kabel utama, kabel penggantung) → *menara kena gaya horizontal*
  4. Kabel ditanam ke blok beton → **angkur**
  5. Angin kencang → *bergoyang, terpelintir* → **flutter** (Jembatan Tacoma)
  6. **Rangka pengaku** di bawah jalan → mobil boleh lewat, angin boleh kencang, jembatan tetap berdiri
- **Penutup:** "Habis ini, bikin apa lagi ya?"

## Gaya visual

- 3D low-poly, warna flat, langit biru, gunung putih, pohon pinus
- Label istilah dalam kotak kuning dengan garis penunjuk
- Panah kuning untuk arah gaya; garis putih untuk efek angin
- Subtitle tengah layar per kata: **kuning** = istilah, **merah** = kegagalan
- Watermark handle + avatar di pojok atas
